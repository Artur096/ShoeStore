# Обувной магазин "СТЕППЕР" 👞

Консольное приложение для управления обувным магазином на C#.

## 📋 Функционал

- **Поиск обуви** — по бренду, модели, размеру, цене
- **Продажа обуви** — полный цикл с проверкой наличия
- **Прием возвратов** — с проверкой срока 14 дней
- **Консультация** — рекомендации на основе предпочтений
- **Статистика** — покупатели, модели, бренды, популярность
- **Регистрация** — новых покупателей с предпочтениями

## 🚀 Запуск

1. Открыть `ShoeStore.sln` в Visual Studio 2022
2. Нажать `F5`
